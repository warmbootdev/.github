<h1 align="center">Organization defaults</h1>

Organization defaults. GitHub uses each file here for any warmbootdev repository
that does not have its own: contributing guide, security policy, issue forms and
the pull request template. `profile/README.md` is the organization's front page.

This repository is public, so it holds nothing internal: hostnames, clusters and
tooling details live in the repositories themselves and in
[warmbootdev/standards](https://github.com/warmbootdev/standards) (private).
